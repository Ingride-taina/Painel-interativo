# Desenvolva Mais

O projeto **Desenvolva Mais** é um site desenvolvido como atividade acadêmica que apresenta um painel interativo construído a partir de dados reais coletados em um salão de beleza. O objetivo é analisar e relacionar as práticas observadas no local com os **Objetivos de Desenvolvimento Sustentável (ODS)** da Agenda 2030.

## Contexto Acadêmico

Este projeto foi proposto como uma atividade prática voltada à aplicação de conceitos de análise de dados, sustentabilidade e comunicação visual. A intenção foi transformar informações coletadas em campo em um recurso digital acessível, claro e alinhado às diretrizes da Agenda 2030.

## Objetivo do Projeto

O site busca demonstrar como práticas cotidianas de um pequeno negócio podem se conectar com metas globais de desenvolvimento sustentável. A partir dos dados coletados, são exibidos indicadores, comportamentos observados e possíveis alinhamentos com diferentes ODS.

## Painel Interativo

O painel apresenta visualizações e informações organizadas para facilitar a interpretação dos dados, permitindo:

- análise rápida das práticas do salão;  
- identificação dos ODS relacionados;  
- compreensão das áreas com potencial de melhoria;  
- reflexão sobre sustentabilidade aplicada a negócios locais.

## Aprendizado

A construção deste projeto me permitiu explorar:

- conexão entre práticas reais e políticas globais de sustentabilidade;  
- desenvolvimento Web com HTML e CSS;  
- comunicação de resultados de forma visual e acessível;  
- aplicação de conceitos acadêmicos em um contexto prático.
